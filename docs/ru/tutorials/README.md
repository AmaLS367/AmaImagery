## API руководства

### [📡 Использование API](./api-usage.md)
Полное руководство по использованию REST API.

**Темы:**
- Аутентификация
- Выполнение запросов
- Обработка ответов
- Обработка ошибок
- Rate limiting
- Webhooks (если доступно)

**Пример:**
```python
import requests

# Вход
response = requests.post('http://localhost:8000/api/v1/auth/login', json={
    'email': 'user@example.com',
    'password': 'password'
})
token = response.json()['access_token']

# Генерация изображения
response = requests.post(
    'http://localhost:8000/api/v1/images/generate',
    headers={'Authorization': f'Bearer {token}'},
    json={
        'prompt': 'красивый закат над горами',
        'negative_prompt': 'размытый, низкое качество',
        'num_inference_steps': 30,
        'guidance_scale': 7.5
    }
)

image_url = response.json()['image_url']
```
