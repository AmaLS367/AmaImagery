# Документация тестирования

## Обзор

Комплексная стратегия тестирования включающая unit тесты, integration тесты, E2E тесты, security тесты и performance тесты для бэкенда и фронтенда.

## Типы тестов

### ✅ Unit тесты
- Бэкенд: pytest
- Фронтенд: Vitest
- Изоляция компонентов
- Моки зависимостей

### 🔗 Integration тесты
- Интеграция API
- Интеграция базы данных
- Интеграция сервисов
- Моки внешних сервисов

### 🌐 E2E тесты
- Полные пользовательские сценарии
- Автоматизация браузера
- Тестирование API контрактов
- Smoke тесты

### 🔒 Security тесты
- Тесты аутентификации
- Тесты авторизации
- Валидация ввода
- Предотвращение SQL инъекций

### ⚡ Performance тесты
- Тесты задержки API
- Нагрузочное тестирование
- Профилирование памяти
- Использование GPU

## Быстрый старт

### Тесты бэкенда
```bash
pytest tests/
```

### Тесты фронтенда
```bash
cd frontend_tests
npm test
```

См. [Запуск тестов](./running-tests.md) для подробностей.
