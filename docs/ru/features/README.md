# Документация функций

## Обзор

Полная документация всех функций доступных в AI Image Generator, включая генерацию изображений, редактирование, увеличение, изменение размера и модерацию контента.

## Основные функции

### 🎨 Генерация изображений
Генерация высококачественных изображений из текстовых промптов используя модели Stable Diffusion.

**Возможности:**
- Генерация text-to-image
- Выбор кастомных моделей
- Продвинутые параметры (шаги, guidance, seed)
- Пакетная генерация
- Негативные промпты

### ✏️ Редактирование изображений
Редактирование существующих изображений с AI инструментами.

**Возможности:**
- Inpainting (заполнение замаскированных областей)
- Outpainting (расширение изображений)
- Image-to-image с промптами
- Перенос стиля с IP-Adapter
- Guidance с Controlnet

### 🔍 Увеличение изображений
Улучшение разрешения и качества изображений.

**Возможности:**
- AI-powered увеличение
- Множественные факторы масштабирования (2x, 4x)
- Улучшение деталей
- Уменьшение артефактов

### 📐 Изменение размера изображений
Эффективное изменение размера и обрезка изображений.

**Возможности:**
- Умная обрезка
- Сохранение соотношения сторон
- Пакетное изменение размера
- Сохранение качества

### 🛡️ Модерация контента
Обеспечение безопасного и подходящего контента.

**Возможности:**
- NSFW обнаружение
- Фильтрация промптов
- Блокировка негативных слов
- Оценка безопасности контента

### 📁 Управление файлами
Управление сгенерированными изображениями и загрузками.

**Возможности:**
- Подписанные URL для безопасного доступа
- Валидация загрузки файлов
- Управление хранилищем
- Автоматическая очистка

## API Endpoints

- `POST /api/v1/images/generate` - Генерация изображений
- `POST /api/v1/images/edit` - Редактирование изображений
- `POST /api/v1/images/upscale` - Увеличение изображений
- `POST /api/v1/images/resize` - Изменение размера изображений
- `POST /api/v1/moderation/nsfw` - Проверка NSFW

См. [API документация](../backend/api/endpoints/images.md) для подробностей.
