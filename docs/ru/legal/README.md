# Юридическая документация

## Обзор

Юридическая информация, лицензирование, атрибуция и обязательства по model assets для **AmaImagery**.

## Краткая сводка по лицензиям

### Код приложения
- корневой `LICENSE`
- open-source путь под `AGPL-3.0-only`
- отдельный путь коммерческого лицензирования в `COMMERCIAL_LICENSE.md`

### Слой моделей / ассетов
- model weights и производные материалы могут иметь отдельные обязательства
- проверяйте `NOTICE.txt`, `ATTRIBUTIONS.md` и license files внутри `models/`
