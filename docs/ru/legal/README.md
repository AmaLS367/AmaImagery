## Обзор

Юридическая информация, лицензирование и обязательства по сторонним компонентам для **AmaImagery**.

## Краткая сводка по лицензиям

### Код приложения
- корневой `LICENSE`
- open-source путь под `AGPL-3.0-only`
- отдельный путь коммерческого лицензирования в `COMMERCIAL_LICENSE.md`

### Слой моделей / ассетов
- model weights и производные материалы могут иметь отдельные лицензионные обязательства сторонних авторов
- проверяйте `NOTICE.txt` и лицензии используемых вами моделей
