## Частые проблемы

### Проблемы установки

#### Проблема: CUDA не найдена
**Симптомы:** `RuntimeError: CUDA not available`
**Решение:**
1. Проверьте установлены ли NVIDIA драйверы
2. Установите CUDA toolkit 11.8+
3. Переустановите PyTorch с поддержкой CUDA
```bash
pip install torch==2.2.2+cu121 --index-url https://download.pytorch.org/whl/cu121
```

#### Проблема: Нехватка VRAM
**Симптомы:** `CUDA out of memory`
**Решения:**
1. Уменьшите разрешение изображения
2. Понизьте `CUDA_VRAM_FRACTION` в настройках
3. Включите выгрузку моделей
4. Закройте другие GPU приложения

### Ошибки выполнения

#### Проблема: Не загружается модель
**Симптомы:** Файлы модели не найдены или повреждены
**Решения:**
1. Проверьте файлы модели в директории `models/`
2. Перезагрузите модели
3. Проверьте права доступа к файлам
4. Проверьте дисковое пространство

#### Проблема: Медленная генерация
**Симптомы:** Генерация занимает слишком много времени
**Решения:**
1. Проверьте использование GPU
2. Включите xformers
3. Уменьшите количество шагов inference
4. Проверьте отсутствие CPU fallback

### Проблемы базы данных

#### Проблема: Ошибки миграции
**Симптомы:** Ошибки миграции Alembic
**Решения:**
1. Проверьте подключение к БД
2. Проверьте что PostgreSQL запущен
3. Проверьте историю миграций
```bash
alembic current
alembic history
```

#### Проблема: Исчерпан пул соединений
**Симптомы:** `QueuePool limit exceeded`
**Решения:**
1. Увеличьте размер пула в настройках
2. Проверьте утечки соединений
3. Перезапустите базу данных

### Проблемы Docker

#### Проблема: Контейнер не запускается
**Симптомы:** Контейнер немедленно завершается
**Решения:**
1. Проверьте логи: `docker logs <container>`
2. Проверьте переменные окружения
3. Проверьте конфликты портов
4. Проверьте монтирование томов

## Получение помощи

1. Проверьте эту документацию
2. Поищите существующие issues
3. Включите debug логирование
4. Соберите сообщения об ошибках и логи
5. Сообщайте о проблемах с:
   - Сообщением об ошибке
   - Шагами воспроизведения
   - Деталями окружения
   - Соответствующими логами

## Режим отладки

Включить debug логирование:
```bash
# .env
DEBUG=1
LOG_LEVEL=DEBUG
```

Просмотр логов:
```bash
# Логи приложения
tail -f logs/app/*.log

# Логи ошибок
tail -f logs/errors/*.log
```
