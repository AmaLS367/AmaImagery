## Краткий справочник

### API Endpoints

| Endpoint | Метод | Описание |
|----------|--------|-------------|
| `/api/v1/auth/register` | POST | Регистрация нового пользователя |
| `/api/v1/auth/login` | POST | Вход пользователя |
| `/api/v1/auth/refresh` | POST | Обновление токена |
| `/api/v1/images/generate` | POST | Генерация изображения |
| `/api/v1/images/edit` | POST | Редактирование изображения |
| `/api/v1/images/upscale` | POST | Увеличение изображения |
| `/api/v1/users/me` | GET | Получить текущего пользователя |
| `/health` | GET | Проверка здоровья |

См. [API справочник](./api-reference.md) для полных деталей.

### Ключевые переменные окружения

| Переменная | По умолчанию | Описание |
|----------|---------|-------------|
| `DATABASE_URL` | - | Строка подключения PostgreSQL |
| `REDIS_URL` | - | Строка подключения Redis |
| `SECRET_KEY` | - | Секретный ключ JWT |
| `FRONTEND_ORIGIN` | - | URL фронтенда для CORS |
| `CUDA_VRAM_FRACTION` | 0.9 | Фракция памяти GPU |
| `MAX_WORKERS` | 4 | Рабочие процессы |

См. [Переменные окружения](./environment-variables.md) для полного списка.

### Частые CLI команды

```bash
# Разработка
python run_dev.py                    # Запуск dev сервера
pytest tests/                        # Запуск тестов
alembic upgrade head                # Запуск миграций

# Docker
docker compose up                   # Запуск контейнеров
docker compose logs -f backend     # Просмотр логов
docker compose down                # Остановка контейнеров

# Скрипты
./scripts/linux/bootstrap.sh       # Инициализация окружения
./scripts/linux/migrate.sh         # Запуск миграций
./scripts/linux/smoketest.sh       # Запуск smoke тестов
```

См. [CLI команды](./cli-commands.md) для полного справочника.
