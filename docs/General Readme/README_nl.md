# genai — Projectgids (Nederlands)

## Overzicht

E2E project voor NSFW-beeldgeneratie.

Vereisten:
- Python 3.11+
- Node.js 18+

PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python run.py
cd frontend
npm install
npm run dev
```

Gebruik relatieve paden (`/generate`) in de frontend zodat Vite-proxy werkt.
