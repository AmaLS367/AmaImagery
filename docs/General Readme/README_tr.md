# genai — Proje Kılavuzu (Türkçe)

## Genel Bakış

NSFW görüntü oluşturma için uçtan uca proje.

Hızlı Başlangıç (PowerShell):

```powershell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python run.py
cd frontend
npm install
npm run dev
```

Geliştirme sırasında frontend'de göreli yollar (`/generate`) kullanın; Vite proxy bunları backend'e yönlendirir.
