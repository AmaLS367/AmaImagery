# genai — Guia do projeto (Português)

## Visão geral

Repositório para geração de imagens NSFW (end-to-end). Contém:
- Backend: Python + FastAPI (porta 8000)
- Frontend: React + TypeScript + Vite (dev em 5173)

Comandos rápidos (PowerShell):

```powershell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python run.py
cd frontend
npm install
npm run dev
```

Use caminhos relativos (`/generate`) no frontend para permitir o proxy do Vite.
