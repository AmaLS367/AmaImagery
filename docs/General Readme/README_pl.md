# genai — Przewodnik po projekcie (Polski)

## Przegląd

Projekt generowania obrazów (NSFW) — backend (Python/FastAPI) i frontend (React/TS/Vite).

Szybki start (PowerShell):

```powershell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python run.py
cd frontend
npm install
npm run dev
```

Używaj relatywnych ścieżek (`/generate`) w frontendzie dla proxy Vite.

(Resztę informacji zawiera `README_en.md`.)
