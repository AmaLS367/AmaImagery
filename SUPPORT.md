# Support

> Use the right lane. It saves everyone time.

AmaImagery has a few distinct support paths, and each one serves a different kind of question.

| Need | Best path |
| --- | --- |
| Bug report | GitHub Issues |
| Product or usage discussion | GitHub Discussions |
| Security disclosure | [SECURITY.md](./SECURITY.md) |
| Commercial licensing or private support | `amalsdev367@gmail.com` |

---

## Public First

If the topic is not security-sensitive and does not require private licensing discussion, prefer the public channel. It leaves a trail, helps future users, and improves the project.

## Private Channels

Use private email when the topic is:

- a vulnerability or exploit path
- a commercial licensing request
- a partnership or private support inquiry

Contact:

`amalsdev367@gmail.com`

Clear routing keeps the project fast, clean, and easier to maintain.
