# README: config

Назначение каталога: хранение словарей и списков для гигиены промта и политик безопасности. Все файлы текстовые, кодировка UTF-8, одна запись на строку. Пустые строки и строки, начинающиеся с символа `#`, игнорируются. Регистр неважен, дубликаты автоматически отфильтровываются при загрузке.

## spell_seed_vocab.txt

Базовый словарь для спеллчекера. Широкое покрытие общих визуальных терминов: цвета, материалы, фото и кинотермины, рендер и шейдеры, арт-стили, анатомия, окружения, UI/UX. Цель: снизить ложные исправления и уменьшить зависимость от внешних библиотек.

Формат:

```
realistic
photorealistic
cinematic
...
```

Когда менять: при расширении предметной области. Добавление новой строки мгновенно влияет на корректировку, так как слово становится известным и не будет предлагаться к правке.

## autocorrect_extra_words.txt

Дополнение к базовому словарю. Содержит редкие и доменные термины, которые не стоит исправлять по сходству: имена планировщиков, специфические эффекты, технические слова.

Формат:

```
dpmsolver
karras
lensflare
...
```

Когда менять: при появлении новых техник, плагинов, модулей. Это безопасный слой для частых несловниковых токенов.

## autocorrect_whitelist.txt

Глобальный whitelist для автокоррекции. Любой токен из этого списка не изменяется ни при каких условиях. Обычно это аббревиатуры, идентификаторы моделей и самплеров, форматы файлов, техническая лексика.

Формат:

```
sd15
sdxl
lcm
lora
vae
ddim
png
...
```

Когда менять: при интеграции новых моделей и инструментов, чтобы исключить их из коррекции.

## negative_whitelist_extra.txt

Расширение whitelist только для негативного промта. Содержит устойчивые фразы и токены, характерные для negative, которые часто выглядят как ошибки, но являются нормой.

Формат:

```
lowres
bad_anatomy
jpeg_artifacts
worst_quality
...
```

Когда менять: при появлении новых устойчивых негативных формулировок. Это защищает negative от навязчивых правок.

## neg_tokens.txt

List of words that are not allowed, its not depends on what mode use user, its just the words that
are not allowed

Format:

```
watermark
signature
logo
qr
timestamp
...
```

Когда менять: при обнаружении новых источников артефактов и спам-шаблонов. Подходит для регулярного пополнения.

## nsfw_blocklist.txt

Жёсткий список для фильтрации NSFW и запрещённого контента. Используется политикой безопасности. Совпадения приводят к блокировке запроса на раннем этапе.

Формат:

```
<токен1>
<токен2>
...
```

Когда менять: при обновлении требований модерации. Изменения требуют внимательной ревизии, так как влияют на доступность функционала.

## Общие правила редактирования

1. Кодировка: UTF-8 без BOM.
2. Разделитель: одна запись в строке, без кавычек.
3. Комментарии: строки, начинающиеся с `#`, игнорируются.
4. Пробелы: ведущие и хвостовые пробелы обрезаются при загрузке.
5. Регистр: приводится к нижнему, сопоставление регистронезависимое.
6. Дубликаты: удаляются при загрузке.
7. Горячее обновление: при перезапуске приложения списки перечитываются. Если нужен hot-reload, добавьте планировщик с периодической перезагрузкой или endpoint админа для invalidate кеша.

## Взаимодействие с кодом

Загрузка выполняется в `prompt_hygiene/settings.py` через функции:

* `load_spell_seed_vocab`, `load_autocorrect_extra`, `load_autocorrect_whitelist`, `load_negative_whitelist_extra`, `load_default_neg_tokens`.
* Кеши в памяти: `SPELL_SEED_VOCAB`, `AUTOCORRECT_EXTRA_WORDS`, `AUTOCORRECT_WHITELIST`, `NEGATIVE_WHITELIST_EXTRA`, `DEFAULT_NEG_TOKENS`.

Назначение в подсистемах:

* `spell_seed_vocab.txt` и `autocorrect_extra_words.txt` формируют словарь `SpellChecker`.
* `autocorrect_whitelist.txt` и `negative_whitelist_extra.txt` защищают токены от правок в соответствующих режимах.
* `neg_tokens.txt` питает `NegList` и валидаторы подсказок.
* `nsfw_blocklist.txt` используется в сервисе безопасности для ранней блокировки.

## Практика обновлений

* Мелкие добавления: правка файлов и перезапуск сервиса.
* Массовые изменения: подготовьте обновлённые файлы отдельно, прогоните тест на коллизии и только затем заменяйте в проде.
* Обратная совместимость: добавление слов обычно безопасно, удаление из whitelist может вызвать неожиданные правки, удаление из nsfw_blocklist снижает строгость модерации.
