# genai — Guida del progetto (Italiano)

## Panoramica

Progetto end-to-end per la generazione di immagini NSFW.

Prerequisiti:
- Python 3.11+
- Node.js 18+

Esegui (PowerShell):

```powershell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python run.py
cd frontend
npm install
npm run dev
```

Usa percorsi relativi (`/generate`) nel frontend per il proxy di Vite.
